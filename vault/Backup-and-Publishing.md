# Backup and publishing

Public Git repository: https://github.com/oroofarm-lang/Casa-Luma-Shop

Site source: main branch, /docs. Public site contains only the complete standalone catalog.

Private original files remain local and are captured in backups/Casa-Luma-full-backup-2026-10-19.zip (ignored by Git). The ZIP was created before Git initialization. It must not be placed in public hosting.
